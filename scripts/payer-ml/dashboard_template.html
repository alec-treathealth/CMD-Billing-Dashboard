    Character-level drift · TF-IDF char n-grams + rapidfuzz edit distance + union-find

    1,500 payer spellings are really 911 payers — and new spellings of known payers now outnumber genuinely new payers 14-to-1

    Clustering every payer string across claims and VOB intake, character n-grams first, edit-distance confirmation second. 258 payers carry more than one spelling; "Anthem BCBS of CA" alone has 62. The dominant character-level edits: a state qualifier appearing/disappearing, small typos, and boilerplate (THE / INC / HEALTH…). The front door and the back door disagree too: "UHC" appears 946× in VOBs and never once in claims, and 57 clusters map to more than one canonical payer id in the crosswalk.

    Driver model · sklearn HistGradientBoosting + permutation importance

    What drives the paid-rate: the code you bill, then the payer, then time itself

    A gradient-boosted model predicting paid-rate at the payer × code × quarter grain explains R² 0.33 on a random split — but scores R² −0.74 when asked to predict the newest quarters from history. That gap is the quantified punchline of this whole page: payer behavior drifts faster than history can predict it. Time (t) ranking third in importance says the drift is systematic, not noise.

    Method, reproduction & caveats

    • ruptures — PELT change-point detection (RBF kernel) on per-payer monthly series
    • scipy — Jensen-Shannon divergence for payer-mix and code-mix drift; PSI vs first-year baseline
    • scikit-learn — char n-gram TF-IDF + cosine for name clustering; HistGradientBoosting + permutation importance
    • rapidfuzz — C++-speed Levenshtein/token-sort confirmation of name merges
    • statsmodels — Holt-Winters exponential smoothing with 4-month holdout backtests
    • pandas / numpy / psycopg3 — aggregate-only pulls as the read-only claims_reader role

    Scripts: scripts/payer-ml/pull_aggregates.py → analyze_behavior.py + analyze_names.py → export_viz_data.py. Caveats: paid-rates use only service months ≥120 days old (payments accrue late — trailing months under-report); partial trailing months dropped; payer families come from the alias crosswalk plus a token heuristic; the CARC panel is a one-month snapshot, not a trend; "(no CPT)" rows are uncoded charge lines in the source reports and were excluded from paid-rate flips; the ERA payment pipeline began 2026-07. Nothing here writes to the database.
